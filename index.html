تسجيل الدخول

اربط حسابك على GitHub لتتزامن بياناتك بشكل خاص بين أجهزتك.

كيف أحصل على المفتاح؟
  1. افتح GitHub ← Settings ← Developer settings
  2. اختار Personal access tokens ← Fine-grained tokens
  3. في Repository access اختار Only select repositories ثم ريبو البيانات
  4. في الصلاحيات أضف Contents واجعلها Read and write
  5. اضغط Generate token وانسخ المفتاح فوراً
الريبو مش موجود؟

يمكن إنشاؤه من هنا كريبو خاص (Private). يلزم مفتاح من نوع Classic بصلاحية repo.

  • 🔒 بياناتك في ريبو خاص على حسابك أنت
  • 🛡 المفتاح يُحفظ على جهازك فقط ولا يُرسل لغير GitHub
  • ☁️ تزامن تلقائي وعمل بدون إنترنت
